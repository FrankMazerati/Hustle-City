# Hustle City Project History Archive

Use this area to preserve original source material as it is recovered. Do not replace the original conversations or images with summaries.

## Suggested layout
- conversations/YYYY-MM-DD/topic.md — exported or copied conversation, preserving speaker turns and date when available.
- visual-references/city/ — city, streets, skyline, districts, buildings and landmarks.
- visual-references/characters/ — character, clothing, hair and appearance references.
- visual-references/vehicles/ — cars, motorcycles, trains, boats and aircraft.
- visual-references/venues/ — clubs, restaurants, shops, marina, airport and interiors.
- visual-references/gameplay/ — UI, cards, social interactions, events and activity references.

## Intake rules
1. Preserve original filenames and dates where possible.
2. Add a short source note for each image: where it came from, what it depicts, and which approved feature it supports.
3. Keep original source material separate from edited, generated, or production-ready assets.
4. Never assume a concept image grants commercial usage rights; record license/provenance when known.
5. Do not put passwords, API keys, private account information, or private player data in this repository.
6. Do not silently promote an idea from a conversation to an approved requirement. Extract decisions into the project decision log and mark unresolved items clearly.

When the creator has gathered the source material, it can be organized and cross-referenced against the database model, game systems, and agent specifications.
