# Hustle City — first browser-playable Godot slice

This is the first implementation foundation, not the finished game.

## Included
- Procedural 3D city block with a Chicago-inspired street layout.
- Third-person player capsule, keyboard movement, mouse look and run.
- Basic building and street collision.
- Preview HUD and simple vehicle/showroom placeholder.
- Godot Web export preset using the Compatibility renderer.

## Controls
- WASD or arrow keys: move
- Mouse: look
- Shift: run
- Escape: release mouse; click to recapture

Open this folder in Godot 4.4.1 or later. The GitHub Actions workflow exports a browser build and attaches it to the run. Merging to main will trigger a GitHub Pages deployment once Pages is enabled.

## Remaining work
Touch controls, character art and animation, vehicle interaction, NPC interaction, sound, authored city assets, and tablet/desktop performance testing remain outstanding.
