# Hustle City Conversation and Reference Archive

Preserve source material that informs the project: exported conversations, design notes, map screenshots, photographs, sketches, reference images and research notes.

## Suggested organization
- conversations/ — exported chat transcripts grouped by date or topic.
- images/maps/ — original city maps, district layouts and neighborhood-box references.
- images/transportation/ — trains, stations, track environments and construction references.
- images/buildings/ — architecture, interiors, streetscapes and construction references.
- images/characters-and-life-simulation/ — NPC, fashion, social and daily-life references.
- research/ — sourced notes, citations, measurements and comparisons.

Git does not retain empty folders; add a README or index when creating a new archive category.

## Archive rules
1. Preserve original exports and images without silently editing them.
2. Use descriptive filenames, e.g. 2026-11-22_transportation_station-reference_01.jpg.
3. Record source, date, creator/owner if known, intended use and license/permission status.
4. Separate source evidence from assistant summaries and interpretations.
5. Do not assume an online image is licensed for redistribution or commercial use.
6. Link important archive items from the relevant framework or asset register.
7. Do not commit credentials, secrets or private information about other people.

When old chats are recovered, preserve the full transcript where possible. Add metadata with conversation title/date, topics, decisions, open questions and links to framework sections. Do not discard context that explains why a decision was made.
