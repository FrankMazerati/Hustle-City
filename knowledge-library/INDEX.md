## Status meanings
| Status | Meaning |
|---|---|
| RAW IDEA | Captured, not evaluated |
| PROPOSED | Organized recommendation awaiting creator approval |
| APPROVED | Explicitly approved by creator |
| IN DEVELOPMENT | Approved and actively being specified or built |
| DEFERRED | Intentionally postponed |
| REJECTED | Considered and declined |
| SUPERSEDED | Replaced by a newer decision; retained for history |

Every major idea needs a source entry, status and (when promoted) a framework link. Every approved system change belongs in the decision register.
